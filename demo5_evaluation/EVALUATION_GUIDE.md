# Evaluation Guide — Microsoft Foundry Built-in Evaluators

Complete reference for all built-in evaluators available in the Microsoft Foundry SDK v2.

## Overview

Evaluators assess AI responses across three dimensions:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    EVALUATION TAXONOMY                                  │
├─────────────┬───────────────────────────────────────────────────────────┤
│ Quality     │ How well-written and coherent is the response?           │
│ Safety      │ Does the response contain harmful or risky content?      │
│ Agent       │ How effectively does the agent complete tasks and        │
│             │ use tools? (Agent-targeted evals only)                   │
└─────────────┴───────────────────────────────────────────────────────────┘
```

## How Evaluators Work

Each evaluator is configured as a `testing_criteria` entry:

```python
{
    "type": "azure_ai_evaluator",
    "name": "my_evaluator",                          # Your display name
    "evaluator_name": "builtin.<evaluator>",          # Built-in evaluator ID
    "initialization_parameters": {                     # Only for AI-assisted evaluators
        "deployment_name": "<your-model-deployment>"
    },
    "data_mapping": {                                  # Map data fields to evaluator inputs
        "query": "{{item.query}}",                     # From your test dataset
        "response": "{{sample.output_text}}",          # Generated by the target
    },
}
```

### Data Mapping Variables

| Variable | Description |
|---|---|
| `{{item.<field>}}` | Field from your test dataset (e.g. `{{item.query}}`) |
| `{{sample.output_text}}` | Agent/model text response |
| `{{sample.output_items}}` | Full structured response (includes tool calls) |
| `{{sample.tool_definitions}}` | Auto-populated tool schemas (for tool evaluators) |
| `{{sample.tool_calls}}` | Extracted tool calls from the response |

## Quality Evaluators

AI-assisted evaluators that judge response quality using an LLM. They return scores on a **1-5 Likert scale** (threshold = 3).

**Require**: `initialization_parameters.deployment_name`

| Evaluator | `evaluator_name` | What it measures | Required fields |
|---|---|---|---|
| **Coherence** | `builtin.coherence` | Logical flow, organization of ideas, clear connections | `query`, `response` |
| **Fluency** | `builtin.fluency` | Grammar, vocabulary, sentence complexity, readability | `response` |

### Example

```python
{
    "type": "azure_ai_evaluator",
    "name": "coherence",
    "evaluator_name": "builtin.coherence",
    "initialization_parameters": {"deployment_name": "gpt-4o"},
    "data_mapping": {
        "query": "{{item.query}}",
        "response": "{{sample.output_text}}",
    },
}
```

### Output

```json
{
    "metric": "coherence",
    "score": 4,
    "label": "pass",
    "reason": "The response directly addresses the question with clear, logical connections.",
    "threshold": 3,
    "passed": true
}
```

## Safety Evaluators

Use hosted safety models (no `deployment_name` needed). They return scores on a **0-7 severity scale** (threshold = 3; score ≤ 3 = pass).

### Content Safety

| Evaluator | `evaluator_name` | What it detects | Applicable to |
|---|---|---|---|
| **Violence** | `builtin.violence` | Violent/threatening language, weapons | Models + Agents |
| **Sexual** | `builtin.sexual` | Sexual/explicit content | Models + Agents |
| **Self Harm** | `builtin.self_harm` | Self-harm related content | Models + Agents |
| **Hate/Unfairness** | `builtin.hate_unfairness` | Hate speech, discrimination, stereotypes | Models + Agents |

All content safety evaluators use the same data mapping:

```python
"data_mapping": {
    "query": "{{item.query}}",
    "response": "{{sample.output_text}}",
}
```

### Severity Scale

| Level | Score Range | Description |
|---|---|---|
| Very Low | 0-1 | Neutral/informational context, appropriate for most audiences |
| Low | 2-3 | Limited detail, not glorifying, historical/fictional context |
| Medium | 4-5 | Direct negative content, moderately detailed |
| High | 6-7 | Extreme content, encourages harmful actions |

### Advanced Safety

| Evaluator | `evaluator_name` | What it detects | Applicable to |
|---|---|---|---|
| **Protected Material** | `builtin.protected_material` | Copyrighted content (lyrics, recipes, articles) | Models + Agents |
| **Indirect Attack (XPIA)** | `builtin.indirect_attack` | Jailbreak attempts injected via context | Models only |
| **Code Vulnerability** | `builtin.code_vulnerability` | Security vulnerabilities in generated code (SQL injection, XSS, etc.) | Models + Agents |
| **Ungrounded Attributes** | `builtin.ungrounded_attributes` | Ungrounded inferences about personal attributes | Models + Agents |

> **Note**: `ungrounded_attributes` requires an additional `context` field in `data_mapping`.

### Agent-only Safety

| Evaluator | `evaluator_name` | What it detects | Required fields |
|---|---|---|---|
| **Prohibited Actions** | `builtin.prohibited_actions` | Agent performs disallowed actions/tool uses | `query`, `response`, `tool_calls` |
| **Sensitive Data Leakage** | `builtin.sensitive_data_leakage` | Agent exposes sensitive information (PII, financial, health) | `query`, `response`, `tool_calls` |

```python
{
    "type": "azure_ai_evaluator",
    "name": "prohibited_actions",
    "evaluator_name": "builtin.prohibited_actions",
    "data_mapping": {
        "query": "{{item.query}}",
        "response": "{{sample.output_items}}",
        "tool_calls": "{{sample.tool_calls}}",
    },
}
```

## Agent System Evaluators

Evaluate the **end-to-end outcome** of the agentic workflow. Binary **Pass/Fail**.

**Require**: `initialization_parameters.deployment_name`

| Evaluator | `evaluator_name` | What it measures | Required fields |
|---|---|---|---|
| **Task Adherence** | `builtin.task_adherence` | Did the agent follow its system instructions and rules? | `query`, `response` |
| **Task Completion** | `builtin.task_completion` | Did the agent fully complete the task with a usable deliverable? | `query`, `response` |
| **Intent Resolution** | `builtin.intent_resolution` | Did the agent correctly identify the user's intent? | `query`, `response` |
| **Task Navigation Efficiency** | `builtin.task_navigation_efficiency` | Did the agent take the optimal sequence of actions? | `actions`, `expected_actions` |

> **Note**: Task Navigation Efficiency requires **ground truth** (`expected_actions`) and cannot be used in a target-based evaluation run. See the special section below.

### Example (Task Adherence)

```python
{
    "type": "azure_ai_evaluator",
    "name": "task_adherence",
    "evaluator_name": "builtin.task_adherence",
    "initialization_parameters": {"deployment_name": "gpt-4o"},
    "data_mapping": {
        "query": "{{item.query}}",
        "response": "{{sample.output_items}}",  # Use output_items for agent evals
    },
}
```

### Task Navigation Efficiency (Special)

This evaluator compares the agent's actual actions against expected actions. It does **not** require a model judge — instead, it uses algorithmic matching.

```python
{
    "type": "azure_ai_evaluator",
    "name": "task_navigation_efficiency",
    "evaluator_name": "builtin.task_navigation_efficiency",
    "initialization_parameters": {
        "matching_mode": "exact_match"  # or "in_order_match" or "any_order_match"
    },
    "data_mapping": {
        "actions": "{{item.actions}}",
        "expected_actions": "{{item.expected_actions}}",
    },
}
```

**Matching modes**:

| Mode | Description |
|---|---|
| `exact_match` | Agent trajectory must match ground truth exactly (order + content) |
| `in_order_match` | All ground truth steps must appear in order (extra steps allowed) |
| `any_order_match` | All ground truth steps must appear (any order, extra steps allowed) |

## Agent Process Evaluators

Evaluate the **step-by-step tool usage** within the workflow. Binary **Pass/Fail**.

**Require**: `initialization_parameters.deployment_name` + `tool_definitions` in data mapping

| Evaluator | `evaluator_name` | What it measures | Required fields |
|---|---|---|---|
| **Tool Call Accuracy** | `builtin.tool_call_accuracy` | Right tools + correct parameters, no redundancy | `query`, `response`, `tool_definitions` |
| **Tool Selection** | `builtin.tool_selection` | Selected correct tools without unnecessary ones | `query`, `response`, `tool_definitions` |
| **Tool Input Accuracy** | `builtin.tool_input_accuracy` | Correct parameters (groundedness, type, format, required, no extra, appropriate values) | `query`, `response`, `tool_definitions` |
| **Tool Output Utilization** | `builtin.tool_output_utilization` | Correctly used tool results in reasoning and final response | `query`, `response`, `tool_definitions` |
| **Tool Call Success** | `builtin.tool_call_success` | Tool calls succeeded without technical errors | `response` |

### Example

```python
{
    "type": "azure_ai_evaluator",
    "name": "tool_call_accuracy",
    "evaluator_name": "builtin.tool_call_accuracy",
    "initialization_parameters": {"deployment_name": "gpt-4o"},
    "data_mapping": {
        "query": "{{item.query}}",
        "response": "{{sample.output_items}}",
        "tool_definitions": "{{sample.tool_definitions}}",
    },
}
```

### Supported Tools

Tool evaluators work best with:
- ✅ File Search, Function Tool (custom functions), MCP, Knowledge-based MCP

Limited support (avoid `tool_call_accuracy`, `tool_input_accuracy`, `tool_output_utilization`, `tool_call_success`, `groundedness` with these):
- ⚠️ Azure AI Search, Bing Grounding, Code Interpreter, Web Search, Fabric, SharePoint

## Evaluation Targets

### Model Target (Demo 5a)

Sends queries directly to a model deployment:

```python
data_source = {
    "type": "completions",
    "source": {"type": "file_content", "content": [...]},
    "input_messages": {"type": "template", "template": [...]},
    "model": "gpt-4o",
}
```

### Agent Target (Demo 5b)

Sends queries to a Foundry agent:

```python
data_source = {
    "type": "azure_ai_target_completions",
    "source": {"type": "file_content", "content": [...]},
    "input_messages": {"type": "template", "template": [...]},
    "target": {
        "type": "azure_ai_agent",
        "name": "my-agent",
        "version": "1",  # Optional: omit for latest version
    },
}
```
